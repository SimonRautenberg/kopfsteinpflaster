This is a private hobby project exploring experimental live-action roleplaying (LARP), collaborative storytelling, and game design.

The project is structured as a small-scale social and narrative system in which emergent stories arise from interacting factions, situational play, and intentionally designed ambiguity.

At its core, it functions as a framework for collaborative fiction-making, combining elements of game design, performative storytelling, and club-based social play.

The setting and materials are intentionally open-ended to encourage interpretation, player agency, and emergent narrative development during play.
